# PCB preparation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A KiCad board, `hw/ecu25kva.kicad_pcb`, ready for hand routing: every footprint, net, net class and rule, with placement by block. Housing-dependent items are placeholders in one table. The layout guide and the field measurement brief go in the bible.

**Architecture:**
- `hw/pcb_rules.py` is pure Python, runs in `.venv`, and is unit-tested. It holds the stack-up, the width calculation, the net classes, the net→class assignment and the `HOUSING` table.
- `hw/gen_pcb.py` runs under **KiCad's bundled Python** (`pcbnew` 10.0.7). It exports the netlist with `kicad-cli`, then builds the board: footprints, nets, outline, holes, contact band, block groups, shelf-packed placement. It also writes the net classes into `ecu25kva.kicad_pro`.
- `hw/check_pcb.py` runs `kicad-cli pcb drc` and checks the board against the rules.

**Tech Stack:** Python 3 (`.venv` for rules and tests); KiCad 10.0.7 `pcbnew` Python at `/Applications/KiCad/KiCad.app/Contents/Frameworks/Python.framework/Versions/3.9/bin/python3`; `kicad-cli` 10.0.7.

**Spec:** `docs/superpowers/specs/2026-10-11-pcb-prep-design.md`

## Global Constraints

- **Stack-up:** 4 layers, 1.6 mm FR-4, Tg ≥ 170 °C. L1 and L4 are 2 oz (0.070 mm); L2 (solid GND) and L3 are 1 oz (0.035 mm).
- **Widths:** for a **20 °C rise at 85 °C ambient**, computed, never typed.
- **Clearances:** IPC-2221B external, uncoated.
  - 100 V class: **0.6 mm**
  - power: 0.3 mm
  - CAN / analogue: 0.2 mm
  - default: 0.15 mm
- **Housing placeholders:**
  - outline 160 × 120 mm
  - 4 × M3 holes at the corners
  - contact band 25 mm deep along the edge opposite J1001
  - J1001 on one long edge, marked "PLACEHOLDER — DO NOT FABRICATE"
  - power-ground pins 1, 2, 5, 6 assumed
- **The schematic is never modified** by this work.
- **The generator refuses to overwrite a board that has tracks** unless `--force`.
- Stock footprints come from `KICAD_FOOTPRINT_DIR`; project ones from `hw/lib/ecu25kva.pretty`.
- **Emissions target: CISPR 25 Class 5** (the owner's decision, 12 Oct 2026). The layout guide treats every switching loop and filter placement as a Class 5 requirement.
- Commits carry no AI trailer.

## Decisions this plan takes

| Item | Choice | Why |
|---|---|---|
| Width formula | IPC-2221 (I = k·ΔT^0.44·A^0.725, k = 0.048 external, 0.024 internal), used in place of the IPC-2152 charts | It has a closed form, and it is the more conservative of the two for these currents (wider traces); the spec says IPC-2152, and this errs safe |
| Board file format | KiCad 10 (from the installed `pcbnew`) | The schematic files stay in v7 format; **the person routing needs KiCad 10**, which the layout guide says |
| Net classes stored | In `ecu25kva.kicad_pro` → `net_settings` (classes + exact-name patterns) | That's where KiCad 7+ keeps them; `gen_project.py` keeps an existing project file, so nothing overwrites them |
| "Power net" for the unclassified check | Any net with a pad on a power part: footprint in TO-252/263, SMPD, SO-8 FETs, inductors, the fuse, or a resistor valued in mΩ | The check catches a new power net that nobody classified |
| J1001 placeholder | `ecu25kva:Bosch_94_PLACEHOLDER`, drawn by `gen_footprints.py`: 4 large pads (pins 1, 2, 5, 6; 2.8 × 5 mm) plus 90 pads at 2.5 mm pitch in 3 rows of 30; silkscreen and fab text "PLACEHOLDER — DO NOT FABRICATE" | Pin numbers match the schematic, so every connector trace lands on the right pad; real geometry replaces it later |
| D806 placeholder | `Diode_SMD:D_SMA` via the `PLACEHOLDER` map in `gen_pcb.py`, not in the schematic | Its part waits on the trip-loop pin; SMA is the likely package |
| Block regions (on the placeholder outline; J1001 on the bottom edge) | contact band (top 25 mm): `injector` power parts, `metering_egr`, `rails`; left of J1001: `power_input`; right of J1001: `can`, `discrete_io`, `speed_inputs`; centre: `mcu`, `sensors_analog`; `connector`: J1001 itself | The spec's §4 zones; the regions are a table, so they move when the housing is measured |
| Placement method | Shelf packing by courtyard bounding box, largest first, 0.5 mm gap, inside each block's region | Deterministic, no overlaps; fine placement is the layout engineer's job |

## Review Focus

1. **A new power net with no class** → `check_pcb` fails, naming the net. Test in Task 1.
2. **Re-running the generator on a routed board** → it refuses without `--force` and leaves the file untouched. Test in Task 2.
3. **A footprint that can't be found in any library** → the generator stops, naming the reference and the library; it never skips the part silently. Test in Task 2.
4. **A block that doesn't fit its region** → the generator stops, naming the block and the shortfall in mm². Test in Task 2.
5. **Sheet-prefixed names** (`/injector/BOOST_100V` vs `/VBAT_INJ`) → assignment matches full names exactly, and a name that matches no net is reported as stale. Test in Task 1.

**Interfaces — Produces:**

def width_mm(amps: float, copper_mm: float, external: bool = True) -> float   # IPC-2221, rounded up to 0.05 mm
CLASSES: dict[str, dict]   # name -> {"amps", "clearance", "track_width" (computed), "via_dia", "via_drill"}
                           # PWR_HI 18 A / 0.6; PWR 6.4 A / 0.3; HV100 1 A / 0.6; CAN 0.2; ANALOG 0.2; Default 0.15

    # -> (assignment for present nets, unclassified power nets, stale ASSIGN names)

### Task 2: Placeholder footprint and the board generator

**Files:**
- Modify `hw/gen_footprints.py` (+ `Bosch_94_PLACEHOLDER`).
- Create `hw/gen_pcb.py`.
- Test: `hw/test_pcb_rules.py`, plus a `--selftest` mode in `gen_pcb.py` run under KiCad's Python.

**Interfaces — Consumes:** everything in Task 1.

**Interfaces — Produces:** `hw/ecu25kva.kicad_pcb`, and `net_settings` in `hw/ecu25kva.kicad_pro`.

The generator:
1. Export the netlist.
2. Load each footprint (`pcbnew.FootprintLoad(lib_dir, name)`), using the `PLACEHOLDER` map for J1001 and D806. Set the reference, value and pad nets.
3. Draw the Edge.Cuts outline, the M3 holes and the contact band (a `User.Comments` rectangle plus a rule-area keep-out for tall parts: none yet).
4. Group footprints per sheet (`PCB_GROUP`).
5. Shelf-pack each group in its region.
6. Place J1001 at `HOUSING["j1001"]`.
7. Add a top-layer text "PLACEHOLDER OUTLINE AND J1001 — DO NOT FABRICATE".
8. Write the classes and patterns into the `.kicad_pro`.
9. Save.

It refuses if the existing board has any `PCB_TRACK`, unless `--force`.

### Task 3: Board check

**Files:** Create `hw/check_pcb.py`.

**Interfaces — Consumes:** `pcb_rules` (Task 1), `hw/ecu25kva.kicad_pcb` (Task 2).

`check_pcb.py`:
- runs `kicad-cli pcb drc --format json --severity-error` and parses the JSON
- parses the board's footprints and nets, and the `.kicad_pro` net classes (via `kicad-cli pcb export` or a direct s-expression read; either is fine)
- prints PASS/FAIL lines in the style of `check_netlist.py`

Checks:

| Claim | Pass when |
|---|---|
| Footprints | 379, with refs equal to the netlist's |
| Placeholders flagged | J1001 and D806 carry "PLACEHOLDER" in their fab text |
| Nets | every netlist net present |
| Classes | every `ASSIGN` net carries its class in the project file; 0 unclassified power nets |
| Widths | each class `track_width` equals `width_mm()` |
| DRC clearance | 0 `clearance`, `courtyards_overlap`, `copper_edge_clearance` and `hole_clearance` errors |
| Unrouted | reported as a count (expected ≈ all) |

The **layout guide** is written for the layout engineer:
1. What's ready, and what's a placeholder, with the "do not fabricate" rule.
2. Stack-up and net classes, from `pcb_rules`.
3. **Per block:**
   - the critical loop
   - the return path
   - the simulation that assumed it (`sim/blocks/*.cir`)
   - what must not be crossed

   The blocks: power input (reverse FETs, clamp, EMI filters), rails, injector (boost switch loop, turn-off loops, high/low sides, the sense shunts), metering/EGR bridge, sensors analog, speed inputs, CAN pairs, MCU decoupling and supervisor.
4. The single-point join of the injector return and the sensor ground, and where it sits.
5. Creepage around 100 V.
6. Test points: one per rail, CAN, crank and cam, the injector sense nodes.
7. KiCad 10 required; how to regenerate rules without touching routing.

The facts come from the schematic sheets' notes and the simulation headers. Read each sheet generator's comments and the matching `.cir` header before writing its block. Copy no numbers that a source doesn't state.
